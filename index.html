Google Drive sync

Keeps a copy in a private app folder in your Google Drive and merges changes from your other devices. Only this app can see that file.

How to get a Client ID (one-time, free)
  1. Open console.cloud.google.com and create a project (any name).
  2. APIs & Services → Library → enable Google Drive API.
  3. OAuth consent screen → External → fill app name and your email → add yourself as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application.
  5. Under Authorized JavaScript origins add your site, e.g. https://yourname.github.io (no path).
  6. Copy the Client ID and paste it above.

Daily tracking

From this date, Home lists any day with nothing noted so you can add it or mark it as no spending.

Starting fresh?

Deletes every entry dated before the start date (expenses, income, money put aside, card payments). Categories, bills, repeats, goals and settings stay. A backup file is downloaded first. Remember to set each card's Owed when you started tracking (Plan → Cards) to what you owe on the start date.

Reminders

Calendar reminders ring even when the app is closed (9am the day before and on the due date). App alerts show warnings when you open Kudukka. On Android, if you installed Kudukka to your home screen, app alerts also remind you about un-noted days while the app is closed (Android decides the exact time).
